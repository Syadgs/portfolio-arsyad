PROJECT 01
Skripsi · S1 Decision Support System

AquaLife

Aquaculture Water Quality Assessment

Aplikasi web untuk menilai kualitas air kawasan budidaya perikanan dengan metode WSM (Weighted Sum Model) dan SAW (Simple Additive Weighting). Dikembangkan sebagai skripsi di Ce-MEBSA UNDIP, berawal dari prototipe yang saya buat saat menjadi anggota tim riset IoT, lalu diperluas menjadi platform lengkap dengan sistem langganan.

Laravel Inertia.js React MySQL Midtrans

PROJECT 02

RWPay

Digitalisasi Buku Kas Warga RW 08 Sambiroto

Aplikasi web yang mendigitalisasi pembukuan iuran kas warga RW 08 Sambiroto, Semarang. Next.js TypeScript Tailwind CSS Supabase PostgreSQL

  • Ekspor laporan kas ke Excel & PDF
